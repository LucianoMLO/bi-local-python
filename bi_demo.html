Sobre este dashboard

Este é um dashboard de demonstração criado para ilustrar o conceito de BI local desenvolvido em Python — tema do artigo "Seu próprio sistema de BI — seguro, gratuito e rodando no seu computador".

Dados: todos os CNPJs, nomes de empresas, valores e indicadores são sintéticos, gerados aleatoriamente. Qualquer semelhança com dados reais é coincidência.

Arquitetura real: em produção, este HTML é gerado automaticamente por um script Python que lê um banco SQLite (Data Warehouse), executa os cálculos de BI e exporta um arquivo por unidade de negócio — com apenas os dados daquela unidade.
